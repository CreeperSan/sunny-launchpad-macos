# 0.2 交互与个性化

本轮针对用户提出的十一项体验调整。

| 项目 | 实现 |
| --- | --- |
| 翻页 | 平移、景深、立方体、淡入淡出、无动画；0～1.5 秒；触控板连续滚动直接更新浮点页进度，结束或取消后吸附 |
| 外屏网格 | 移除 1240 点网格和 88 点图标上限，按可用屏幕比例计算；图标和间距分别可在 50%～150% 微调 |
| 开关过渡 | 默认从较大图标缩远进入、放大离开；可选淡入淡出、上浮、无动画；时长独立设置 |
| 行列 | 主网格每行 4～12 项、每列 3～8 项；变更时保持线性顺序及文件夹身份，按新容量分页并先备份 |
| 分页器 | 圆点、胶囊、数字；每个页码及左右箭头均为 44×44 点热区；页数较多时横向滚动 |
| 输入 | 水平／垂直鼠标滚轮翻页，触控板连续进度；方向键显示选择框，Return 启动；保留输入法候选及文件夹名称编辑的按键 |
| 覆盖系统栏 | 默认启用 hideDock + hideMenuBar，收起／失活恢复原展示选项；刘海仍作为安全区域 |
| Command + Tab | accessory / LSUIElement 模式，隐藏运行项；运行中也不常驻 Dock，可手动固定 app 作为入口 |
| 图标 | app 内 ICNS 与启动时 applicationIconImage 均指定为 Sunny 图标 |
| 文件夹 | 中心悬停 650ms 后才允许成组；虚线等待／强调框准备、插入线提示排序；单应用文件夹解体；布局及展开过渡动画 |
| 设置侧边栏 | 整行 contentShape 扩大点击区域；新增“交互与布局”分区 |

百分比是相对自动计算值的微调；图标和间距受单元格与可用屏幕限制，避免极端行列配置造成重叠。主网格自定义行列，文件夹仍独立使用 7×5 容量。

## 数据与架构

新增 InteractionPreferences，老版 Preferences 缺少此字段时补默认值，schema 仍为 1；未知或非法配置拒绝保存。动态主页面容量贯穿扫描、拖放、成组、导入提交和状态校验。

连续翻页通过 InteractivePager 与浮点 pagePosition 实现，平台事件桥只转换输入，不改写布局。设置改变行列调用领域 repaginate；风格、主题、图标大小和间距改变不重新排序。

## 验证与限制

自动化覆盖旧偏好读取、容量改变后顺序不丢失、大屏图标及单元格增长、多语言键完整、小屏密集布局边界。构建和 ad-hoc 签名校验执行。

隔离 bundle ID 测试包已启动。GUI 自动化期间窗口状态发生变化，分页点击、真实触控板连续进度、文件夹悬停手感、Command + Tab、Dock 图标缓存与多屏覆盖仍需人工确认，未标记为端到端通过。默认缩远方向参考经典 Launchpad，尚未进行 macOS 15 逐帧曲线对照。

平台依据：[NSApplication 展示选项](https://developer.apple.com/documentation/appkit/nsapplication/presentationoptions-swift.struct)、[辅助应用模式](https://developer.apple.com/documentation/appkit/nsapplication/activationpolicy-swift.enum/accessory)。
