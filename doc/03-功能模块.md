# 功能模块

| 模块 | 职责 | 输入 / 输出 | 不负责 |
| --- | --- | --- | --- |
| 启动器窗口 | 展示、隐藏、屏幕选择、Dock 再激活 | 用户动作 → 窗口状态 | 布局序列化 |
| 应用目录 | 扫描应用、稳定身份、检测失联 | 文件系统 → ApplicationRecord | 决定布局顺序 |
| 布局编辑 | 页面排序、移动、成组、改名、约束 | Layout + 命令 → 新 Layout | UI 动画和 SQLite |
| 搜索 | 名称过滤、确定性结果 | 目录 + 关键词 → 应用列表 | 改写目录和位置 |
| 应用启动 | 文件存在检查、NSWorkspace 打开 | ApplicationRecord → 成功／错误 | 隐式安装应用 |
| 旧布局迁移 | 发现、隔离快照、校验、解析、预览 | 旧 db → ImportPreview | 修改旧系统布局 |
| 数据管理 | 版本、原子保存、备份、恢复 | WorkspaceState ↔ JSON | 判断拖放语义 |
| 设置 | 通用、外观、导入、关于 | 用户选项 → Preferences | 持有平台服务实现 |
| 系统入口 | 菜单栏、Dock、全局快捷键 | OS 事件 → 显示／隐藏 | 私有系统手势 |

布局、应用目录和设置一起保存在带版本的状态快照中，避免“改了网格尺寸但布局尚未重排”这样的跨文件中间态。界面临时状态（当前页、搜索、展开文件夹）不写盘。
