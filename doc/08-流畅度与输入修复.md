# 0.3 流畅度与输入修复

日期：2026-11-14。针对用户截图与九项反馈进行调整。

## 原因与修改

1. 主分页器位于左右网格留白内部，并在内部宽度裁剪，导致滑动图标在留白边缘被截断。改为屏幕宽度的分页视口，留白移入每个页面内部；文件夹继续在面板边界裁剪。
2. 原系统展示选项只有 app 活跃后才有效。新增激活时重应用，覆盖模式同时把窗口置于菜单栏之上；关闭覆盖或收起时还原展示选项及窗口层级。物理刘海区域仍保留安全距离。
3. 壁纸模糊采样触及图片边缘。壁纸放大 128 点后再模糊并裁剪，避免边缘采样产生暗边；进入退出只变换内容，不再缩放整张壁纸。
4. 重复打开会重建 HostingView、同步加载壁纸，并等待扫描后才展示。现在按屏幕／边界缓存视图、复用壁纸，窗口立即显示，目录准备独立进行，初次可显示加载状态。
5. 图标读取原先每次从目录线性查找。状态更新时建立索引，图标视图按 ID 直接读取；图标图片继续使用缓存。
6. 去除文件夹打开时整页图标的实时模糊，使用背景淡化与缩放。文件夹按所点击图标所在方向从小尺寸展开，使用阻尼过渡，避免整页离屏模糊开销。
7. 加入空白背景鼠标拖动翻页；触控板与滚轮均连续更新页位置，停止或取消时吸附。为缺少完整 phase 的设备加入延迟吸附兜底，避免停在半页。图标自身的拖动仍用于整理。
8. 分页器整块增加 AppKit 命中层，消费鼠标按下与抬起；左右按钮独占 44 点，剩余区域平分给页码，点击不会传到关闭背景。页码外观仍由 SwiftUI 渲染。
9. 六项数字配置改为滑块＋数字输入框。滑块拖动只改本地草稿，结束后保存；数字输入按回车或失焦提交。行列取整数，大小／间距为百分比，时间以秒计。

## 性能判断与边界

本轮定位到明确的首帧等待、重复 I/O、视图重建与实时大面积模糊开销，不能仅通过增加动画时长修复。保留用户配置时长，移除这些开销，并交付 Release 优化构建。

尚未使用 Instruments 采集真实显示器上的帧时间，因此不声称已经证明“无掉帧”、达到固定 FPS，或与 macOS 15 的曲线完全一致。触控板、菜单栏覆盖、命中层、文件夹展开仍需实机视觉验收。

## 验证

17 个自动化测试通过，新增连续位移／松手吸附／取消还原用例；其余覆盖数据隔离、迁移、布局和小屏边界。`git diff --check` 通过。构建与签名结果在本轮交付时确认。

设置与布局数据继续使用自有目录，不修改 Dock 数据或系统 Launchpad 数据。
