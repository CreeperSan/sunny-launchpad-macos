# 任务拆解与当前进度

当前交付：0.4.0 开发预览版。第一阶段已落地，不等同于完整旧启动台复刻验收完成。

## M0：调研与架构（已完成）

- [x] Apple 旧版使用说明、SQLite WAL 边界、遗留数据库真实结构核对。
- [x] 需求、交互、模块责任、技术依赖和数据隔离文档。
- [x] 四个 Swift 编译模块与系统 SQLite 桥接，零第三方运行时依赖。

## M1：可运行预览（已实现）

- [x] 应用目录扫描、图标、启动、搜索、分页与菜单栏入口。
- [x] 布局编辑规则、拖放入口、右键跨页移动、文件夹与命名。
- [x] 独立设置：通用、外观、布局与导入、关于。
- [x] 经典 / Liquid Glass、系统 / 深 / 亮主题、八种语言选择。
- [x] 旧库发现、隔离复制、校验、预览、应用；缺失应用占位。
- [x] 原子持久化、覆盖前备份、导出、恢复、损坏保护。
- [x] 鼠标所在屏幕、安全区域、尺寸计算、屏幕变更通知。
- [x] 自动化测试、本地 app 打包与 ad-hoc 签名。

## M2：旧版交互精修（待继续）

- [x] 原生拖拽位置预览、悬停文件夹展开；连续跨页操作仍需人工验收。
- [ ] 整理模式抖动动画及更细腻的过渡；支持减少动态效果。
- [ ] 拖放取消、长按竞争、连续跨页拖放的人工验收和修正。
- [ ] 键盘选择非搜索图标的可见焦点、文件夹内名称编辑与导航焦点完善。
- [x] 目录事件监听、自有图标缓存、首次骨架、60 分钟按需静默刷新。
- [ ] 自定义全局快捷键录制、登录启动；目前只有固定快捷键开关。
- [ ] 历史 macOS 版本数据库样本矩阵及活跃源备份指引。

## M3：正式发布前验收

- [ ] macOS 26 真机（当前开发机为 macOS 27.2），Intel 与 Apple Silicon 构建矩阵。
- [ ] 多显示器热插拔、不同主屏、竖屏、Dock 三种位置、Spaces 与全屏应用共存。
- [ ] VoiceOver、中文输入法候选、增大对比度、不同语言的完整人工校对。
- [ ] 大目录性能与长时间运行；快捷键真实键盘输入和冲突场景。
- [ ] Developer ID 签名、公证、发行包、版本升级／迁移策略。

所有后续任务沿现有边界增量实现，不为计划中的功能提前加入插件框架或服务定位器。

## 0.2 增量

已接入自定义动画、连续页进度、动态网格、行列、分页器热区、辅助应用模式和系统栏覆盖。上述 M2 清单中的视觉与键盘项目已有实现，体验验收仍待完成；本轮准确范围见 [交互与个性化](07-交互与个性化.md)。
