# 技术架构与数据边界

## 选择

Swift 6 + Swift Package Manager；最低 macOS 26；SwiftUI 负责视图，AppKit 负责窗口、图标和系统整合；系统 SQLite 只用于旧库副本解析。无第三方依赖。通过脚本打包标准 `.app`；Xcode 可直接打开 Package.swift。

## 编译级隔离

```text
SunnyLaunchpad（组装根、AppDelegate、入口）
  ├── SunnyPresentation（SwiftUI、窗口交互、可观察状态）
  │      └── SunnyDomain（实体、编辑规则、服务协议）
  └── SunnyInfrastructure（文件、应用扫描、旧库读取、系统服务）
         ├── SunnyDomain
         └── CSQLite（系统库桥接）
```

Presentation 通过协议使用基础设施，由入口注入。Domain 仅依赖 Foundation；禁止平台窗口对象渗透。避免泛型仓储、全局服务定位器和为每个简单函数制造协议。真正的替换点是扫描、存储、导入和启动。

## 模型

- ApplicationRecord：bundle ID 优先的稳定 id、显示名称、路径、可用状态。路径只用于定位，不从旧库任意执行命令。
- Layout：根页面数组；每页有序 LayoutItem。Item 是 app 引用或文件夹；文件夹包含有序子页面，不嵌套。
- WorkspaceState：schemaVersion + layout + catalog + preferences。
- ImportPreview：候选布局、匹配数量、缺失应用、警告，尚未提交。
- ID 唯一、应用只能出现一次、引用必须存在、行列范围、文件夹只含应用作为保存前不变量。

## 存储

默认位置：`~/Library/Application Support/com.creepersan.SunnyLaunchpad/workspace.json`。

- JSON 带显式版本，便于调试和未来迁移；规模是数百到数千个图标，无需先搭复杂数据库。
- actor 串行读写；写入前校验，使用原子替换；修改已有文件前复制为 `Backups/` 下唯一命名的快照。
- 保存成功才更新可观察状态；磁盘错误不会伪装成持久化成功。
- 损坏数据／未来 schema 版本保留原件，进入只读保护；不 catch 后直接生成并覆盖。
- 快照导出、恢复均通过服务边界；恢复前同样备份当前布局。
- 开发可用 `SUNNY_DATA_DIR` 指定隔离目录，不污染正式数据。

## 旧库适配器

自动发现优先当前用户 Darwin 用户目录，随后临时目录同级 0 目录，再检查旧 Dock 目录；手选文件兜底。只读取候选文件，未知 schema 报错。

复制 db 与可选 WAL，两次字节比较确保未观察到变化，拒绝非空回滚日志；在临时副本上建立只读 SQLite 连接。检查 quick_check、表字段、根标识，再按 parent_id + ordering 遍历可见树；跳过暂存页。设置大小／节点上限以拒绝异常输入。

匹配先用 bundle ID；缺失项采用稳定占位身份，之后扫描只更新应用信息而不重排。源路径仅用于预览，不写回，不读取／执行旧书签中的外部代码。

## 并发与平台服务

扫描、文件读写、导入放在 actor 上离开主线程；NSWorkspace 图标与窗口放 MainActor。模型是 Sendable 值类型。界面串行提交编辑，刷新与导入期间禁用竞争编辑。无主线程目录遍历或 SQLite 查询。

## 后续扩展

- 换存储：替换 WorkspaceRepository，先迁移同一领域模型。
- 换扫描源：ApplicationCatalog 提供新实现；目录增量通知不改变布局规则。
- 换旧库版本：按 schema 增加适配分支和固定测试样本，禁止猜测成功。
- 搜索、快捷键、登录启动：分别扩展纯搜索规则和系统入口服务。
- 不预先引入插件运行时、依赖注入框架或跨进程服务。

## 视觉与国际化扩展点

`PanelSurface` 统一处理经典材质、Liquid Glass 和辅助功能降级；采用 [Apple 原生 Liquid Glass API](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views)。内容视图和编辑规则不随风格复制。`Theme` 独立控制 AppKit appearance 和 SwiftUI colorScheme。

`AppLanguage` 在 Domain 定义选择及系统语言匹配，七个独立 JSON 词典由 Presentation 资源包加载。使用稳定语义键与英文兜底，SwiftUI 和 AppKit 菜单使用同一个查询入口；资源完整性由测试约束。新增语言不改变领域编辑或存储逻辑。
