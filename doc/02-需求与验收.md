# 第一版需求与验收

## 产品范围

Sunny Launchpad 是 macOS 26+ 原生桌面启动器。优先保留“我记得这个应用在这一页这个位置”的使用方式。第一阶段交付可构建、可启动的开发预览版；完整体验验收与签名发布分阶段完成。

## 必须具备

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| R01 | 全屏网格启动 | 在当前鼠标屏幕打开；点击应用启动成功后收起；失败显示原因 |
| R02 | 分页 | 点击页码、水平滑动、Command + 方向键可翻页；边界不越界 |
| R03 | 搜索 | 自动聚焦；大小写／重音不敏感；中文原文可查；Return 启动选中结果；空结果可辨认 |
| R04 | 整理 | 拖动排序、拖到图标中间建文件夹／加入、跨页移动；重启后保存 |
| R05 | 文件夹 | 打开、重命名、内部翻页、移出；文件夹不嵌套；空文件夹自动清理 |
| R06 | 独立设置窗口 | 通用、外观、布局导入、关于分区；设置关闭不退出常驻 app |
| R07 | 旧布局导入 | 自动查找／手选，先预览后应用；保留顺序、文件夹、缺失项；格式不支持明确报错 |
| R08 | 自有存储 | 只写 Sunny 数据目录；原库及 WAL／SHM 内容和修改时间不变；覆盖前备份 |
| R09 | 数据失败保护 | 损坏或新版本数据不自动重置；阻止写入并显示原因 |
| R10 | 应用发现 | 常见系统、用户应用目录；跳过 app 内部助手；新增追加，失联保留占位 |
| R11 | 系统入口 | Dock、菜单栏、可关闭的固定全局热键；注册冲突可见 |
| R12 | 可维护性 | 模块单向依赖；领域不引用 AppKit／SwiftUI／SQLite；重要行为有测试 |

## 交互状态

- Esc：先清空搜索 → 再关文件夹 → 再退出整理 → 最后收起启动器。
- 空白点击：文件夹打开时先关闭文件夹，否则收起启动器。
- 搜索结果不允许拖动改变布局，避免过滤视图产生不确定的位置。
- 拖放目标区分：图标中心是成组，边缘是排序。页码可作为跨页落点；右键菜单提供可发现的移动入口。
- 导入不自动启动任何应用；丢失的应用显示占位并说明不可启动。
- 导入、恢复、持久化失败不呈现“成功”；布局只在保存成功后发布到界面。

## 暂不承诺

实际卸载应用、私有触控板手势、接管 F4 系统动作、触发角改写、iCloud、第三方插件、动态壁纸动画、下载进度、通知角标、自动分类、嵌套文件夹。拼音／模糊搜索、任意快捷键录制和登录启动作为后续增量；不影响当前分层。

## 发布验收环境

macOS 26 真机与当前开发机分别验证；多显示器、Retina、不同分辨率、中文输入法、VoiceOver、减少动态效果、启动失败、导入格式差异与大应用量。未执行项目必须保留待验标记。

## 追加确认：风格、主题与语言（2026-11-13）

- 界面风格：经典启动台 / Liquid Glass；默认 Liquid Glass，两项使用单选按钮，立即生效且保存。
- 主题：跟随系统 / 深色 / 亮色；默认跟随系统，使用单选按钮。窗口、文字、材质跟随；与风格独立。
- 语言：跟随系统、简体中文、简体粤语、繁体中文、繁体广东话、英语、日语、韩语；默认跟随系统，八项使用下拉。
- 应用内选择语言后，菜单、设置、启动器文案和领域错误立即更新；原生文件选择器的系统按钮、系统返回的错误详细文本仍由 macOS 语言决定。
- yue-Hans / yue-Hant 分开维护，不把广东话当作繁简转换；香港中文 zh-HK 映射繁体中文，yue-HK 映射繁体广东话。
- 用户文件夹名称与第三方应用名称不翻译；新增文件夹使用当前语言的默认名字。
- 所有语言资源具有相同键集；翻译已提供，日／韩／粤语仍建议由母语使用者校对。
- Liquid Glass 使用 macOS 26 原生 `glassEffect`；减少透明度时降级不透明底色，减少动态效果时停用过渡。
